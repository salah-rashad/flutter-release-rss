# RSS feed to get Flutter releases

This is unofficial RSS feed to get Flutter releases.
The data source is <a href="https://docs.flutter.dev/release/archive">Flutter SDK archive</a>, and observe it daily by GitHub Actions.

- <a href="https://salah-rashad.github.io/flutter-release-rss/releases_windows.xml">:paperclip: Windows</a>
- <a href="https://salah-rashad.github.io/flutter-release-rss/releases_macos.xml">:paperclip: macOS</a>
- <a href="https://salah-rashad.github.io/flutter-release-rss/releases_linux.xml">:paperclip: Linux</a>

## Slack

The code was updated to be work with Slack's `/feed` command specially.

### Usage:

```markdown
/feed subscribe https://salah-rashad.github.io/flutter-release-rss/releases_macos.xml
```
